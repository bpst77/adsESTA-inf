## 📌 Sobre o Projeto

Projeto de Estatística Aplicada explorando a associação entre segurança pública e saúde mental nos EUA. Com foco em AED, cálculo de dados de estatística(testes de hipótese, variâncias, gráficos) usando Python, Pandas e SciPy.

Este projeto foi desenvolvido como requisito para composição de nota.

---

## 🛠️ Detalhes

* **Objetivo:** *Explorar e validar estatisticamente a relação entre os dados de detenções policiais no Arizona e a prevalência de indicadores de Ansiedade e Depressão na região.*
* **Metodologia:** *O projeto aplicou as três áreas da Estatística em rotinas de código Python, utilizando as bases de dados provindas de dados abertos do [governo estadunidense](data.gov) de prisões e indicadores de saúde.
* **Tecnologias:** *Desenvolvimento colaborativo utilizando Google Notebooks e sua integração com Python, juntamente com a biblioteca Pandas e SciPi.*

---

## 🎯 Tópicos de estatística


* **Descritiva:** Gráficos de tendências temporais, Boxplots por gênero, Tabela de Contingência/Qui-Quadrado.
* **Probabilidade:** Cálculo da Probabilidade Condicional Probabilidade de Mulher Detida, dado que o Indicador está Alto.
* **Inferência:** Teste t de Hipótese para comparar a diferença de médias dos indicadores entre anos (ex: 2023 vs. 2022).
